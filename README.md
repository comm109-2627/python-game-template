Python Game Project
----------

Use this Repository to plan and design your Python Game(s). 

Start by writing some notes on what the game is and what information needs be stored while you are playing.

Write these in file PLANNING.txt

What Python objects can be used to store this data.

What information do you need to collect from the player(s).

Can you think how you can break up the steps needed to run the full game into a number of smaller tasks that can be written as functions.

When you are ready start coding your game functions in a Python file e.g. `hangman.py` `snakes-and-ladders.py` etc
